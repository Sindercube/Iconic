# ⭐ About

**Iconic** is a **Fabric Client-Side Mod** which un-hardcodes a bunch of features for other mod developers to modify.

> [!WARNING]
> Iconic is currently in an early state, and is prone to breaking changes.

# 📘 Features

- Add new splash texts which don't override existing ones.

> For a full list of features, and documentation on how to use them, check out the [wiki](iconic.sindercu.be/).

# 👥 Users

- **W.I.P.**

> For a full list of projects that use **Iconic**, go [here](https://github.com/topics/uses-minecraft-iconic).

# 📝 Credits

- The `minecraft:five` font added by the mod is inspired by the Five font from Minecraft: Bedrock Edition.
- The implementation of the emote system is similar to the one added by [Emoji Type](https://modrinth.com/mod/emoji-type), but the emotes suggested to you are defined in resource packs, not in a config file.
